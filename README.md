# Rocket Leaf

Rocket Leaf is a cross-platform RocketMQ 4.x / 5.x desktop client built with Electron and a private local Go daemon.

The application supports connection profiles, topics, consumer groups, messages, cluster metrics, ACL management, local encrypted credentials, configuration migration, and automatic updates on macOS, Windows, and Linux.

For development, architecture, security, and packaging instructions, see the [简体中文说明](README.zh-CN.md).
