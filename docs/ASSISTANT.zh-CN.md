# AI 助手

[English](ASSISTANT.md)

按 <kbd>⌘J</kbd>（Windows 和 Linux 上是 <kbd>Ctrl+J</kbd>），当前页面旁边就会打开 AI 助手。可以问它某个消费组为什么堆积、死信是怎么来的、集群现在健不健康：它用和 [MCP server](MCP.zh-CN.md) 同一套工具读取 broker，根据读到的东西回答；要改动什么，都先等你批准。它跑在你自己选的模型服务上，可以是云端的，也可以是这台机器上的。

## 设置

设置 → AI 助手 → **添加模型服务**：

| 服务类型 | 能接的服务 |
| --- | --- |
| Anthropic | Messages API，走官方 SDK，需要 API Key。 |
| OpenAI 兼容 | 所有说 chat completions 的服务：OpenAI、DeepSeek、通义千问（兼容模式）、Kimi、智谱、SiliconFlow、OpenRouter，以及本机上的 Ollama、LM Studio（不需要 Key）。 |

Base URL 只在不是服务官方地址时填写；模型可以点 **获取列表** 选，也可以直接填 ID。**测试连接** 会真的发一次带工具的小请求，不支持工具调用的模型在这里就会暴露，不用等到第一次提问。**高级** 里可以给这个服务单独设代理（不设就读 `HTTPS_PROXY`）；Anthropic 的服务还可以设置「拒答时换模型重试」，Base URL 指向不转发这个参数的网关时要关掉。

Key 用和连接凭证同一把密钥加密保存在本机。页面上只显示「已配置」，导出配置时不会带上它，也不会读任何环境变量：请求里只有你在这里配置的东西。

## 发出任何东西之前

第一次用某个模型服务时，侧栏会说明哪些内容会发过去、发到哪里：你的问题、当前页面的上下文，以及工具读到的集群数据（消息正文按设置截断或不发）。你同意之前什么都不会发出去；每个服务各同意一次。

## 提问

- **打开**：标题栏的按钮、<kbd>⌘J</kbd>，或者命令面板：按 <kbd>⌘K</kbd> 输入问题，选 **问 AI 助手**。
- **它知道你在看什么。** 当前连接、页面、命名空间，以及详情面板里打开的对象，会随下一条消息一起发出，显示在输入框上方；不想带上的可以删掉。
- **读操作直接执行。** 多次调用折叠成一行「调用了 3 个工具」，展开能看到每次调用的参数和结果。
- **只用窗口里已经打开的连接。** 它不会自己去连；工具说某个连接没打开时，在窗口里连上就行。
- **停止** 会结束这一轮。出错、被停止、或者用满 25 次工具调用的一轮，可以在最后一条提示上重试或继续。

## 写操作等你批准

- **建目标、发消息、重投死信、移动位点**：会停在一张卡片上，写明连接、参数，以及这个连接对这个操作的后果说明。可以批准一次，也可以本会话内不再询问。拒绝就是最终结果，模型会被告知。
- **清空和删除**：每次都要确认，问题和 MCP server 问的一样（目标、所在连接、现在有多少条消息），不能事先批准。
- **只读**（设置 → AI 助手）：模型根本拿不到写工具。
- **每个写操作都有记录**：写进 `agent-audit.jsonl`，和 MCP server 共用一份，连同它是怎么被放行的（一次、本会话内、确认）。

工具返回的内容一律当作 broker 的数据：消息正文里写了什么，都不会被当成指令；每个写操作照样等你批准。

## 会话

侧栏顶部的时钟按钮打开历史会话，按最后更新的日期分组：可以搜索、接着聊、重命名、导出 Markdown、删除。接着聊时沿用这个对话当初的模型服务和模型。

对话加密保存在本机，默认 30 天。设置 → AI 助手里可以改成 7 天、90 天或不保存（会删掉已经保存的），也可以 **清空会话**。

## 哪些东西会离开这台机器

只有对话需要的：你的消息、它的上下文，以及工具读到的东西。每个工具结果最多 32 KB，消息正文按设置截断（不发、2、8 或 32 KB）。用 Ollama、LM Studio 这类本机模型时，什么都不会离开这台机器。

## 出错时

失败的一轮会说明原因，用的是设置页测试连接时的同一套说法：

| 原因 | 检查什么 |
| --- | --- |
| 服务拒绝了这个 Key | Key 本身，以及它是否属于这个 Base URL |
| 没有这个模型 | 模型 ID，或者 Base URL 是不是服务本身 |
| 服务不接受这个请求 | 模型是否支持工具调用；经过网关时，在「高级」里关掉「拒答时换模型重试」 |
| 服务暂时限流、服务端出错 | 等一会儿再重试——在这之前已经自动重试过两次 |
| 连不上这个服务 | 地址和代理 |

它是怎么做的、为什么这样做，见 [AGENT_IN_APP_PLAN.md](AGENT_IN_APP_PLAN.md) 和 [ARCHITECTURE.md](ARCHITECTURE.md)。
